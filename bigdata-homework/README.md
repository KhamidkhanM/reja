# 빅데이터처리 과제

| 파일 | 문제 |
|---|---|
| q1_weather.py | 1. 서울 vs 제주 1~2월 기온 비교 |
| q2_q3_population.py | 2. 지도에 남녀 인구 표시 / 3. 여초 지역 찾기 |

CSV 열 이름이 다르면 스크립트 상단의 이름만 바꾸면 됩니다.
